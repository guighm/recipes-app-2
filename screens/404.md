# 404 — Página não encontrada (`*`)

**Arquivo:** `frontend/src/pages/NotFoundPage.tsx` · **CSS:** `NotFoundPage.css`

Rota curinga: exibida para qualquer URL não mapeada (ex.: `/foo`, `/recipe/`
sem id). Não consulta a API nem depende de autenticação — é estática.

## Estrutura

- Título: **"Erro 404"**.
- Texto: "A página que você procura não existe!"
- Link **Voltar para a Home** (`.ancora`) → `/`.

Como todas as rotas, é renderizada dentro do layout compartilhado (`Header` +
`Footer`), então o usuário mantém a navegação disponível no topo.

## Melhorias sugeridas

- **Botão "Voltar":** além do link para a Home, um botão `navigate(-1)` devolve
  o usuário exatamente de onde veio (erros de digitação de URL em uma página
  interna, por exemplo).
- **Ilustração e tom leve:** a tela é só texto; um prato vazio 🍽️ ou uma
  ilustração de "receita não encontrada" deixa o erro mais simpático.
- **Links úteis:** sugerir destinos ("Ver minhas receitas", "Criar receita")
  dá ao usuário perdido algo para fazer, em vez de um beco sem saída.
